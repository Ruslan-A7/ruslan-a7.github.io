# RA7 Digital Card

Статична PWA-візитівка з 3D-карткою, двома мовами, окремою ліцензією та offline-кешем.

## Запуск

Потрібен HTTP-сервер, оскільки service worker не працює з `file://`:

```powershell
python -m http.server 4173
```

Після цього відкрийте `http://localhost:4173/`.

## Налаштування профілю

Змініть об'єкт `profile` на початку `app.js`. Власний аватар можна покласти в `assets/` і вказати його шлях у полі `avatar`. Посилання GitHub і Telegram редагуються в `index.html`.

Маршрут ліцензії: `/mylic/` (сервери зі стандартним directory index також відкриють `/mylic`). Щоб додати власну довгу ліцензію, замініть файл `LICENSE.md` у корені проєкту, зберігши саме це ім'я. Сторінка відображає заголовки, абзаци, списки, цитати, code block, посилання та базове inline-форматування Markdown; файл кешується service worker.
